### Why This Project Uses the AGPLv3?

This project is licensed under the GNU Affero General Public License v3.0 (AGPLv3) because we believe software that benefits a community should remain available to that community. It was chosen to ensure all users, regardless of if they run the software themselves or use it via a hosted service, should continue to have access to the source code and all improvements made to it.

AGPLv3, unlike most other open source or copyleft licenses has an irrevocable requirement to make the source code available to all users, including those using a hosted service. We beleive that this is for the greater good ("the greater good" of the community), using the software as it:

* Protects user freedom by ensuring access to the source code is preserved.
* Forces all entities to provide their improvements and modifications back to the community.
* Prevents closed source forks from taking community work private while still benefiting from upstream contributions.
* Supports transparency and trust within the community as all code must be provided to users.

* The goal is not to restrict use, especially commercial use, but to ensure that the freedoms granted to one user are preserved for all future users as well.

If you build on this project, offer it as a service, or modify it for your organization, we ask that you contribute back in the same spirit in which the software was shared with you.
